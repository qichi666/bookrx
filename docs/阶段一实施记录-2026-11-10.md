### N1 主题切换

| 文件 | 改动 |
|---|---|
| `src/lib/theme.ts`（新） | `parseTheme` / `nextTheme` / `themeAttr` / `readTheme` / `applyTheme` / `saveTheme`；`auto` = **移除属性**，不写 `data-theme="auto"` |
| `src/tokens.css` | media 块选择器改为 `:root:not([data-theme="light"])`，新增 `:root[data-theme="dark"]`（两组值必须逐字相同，已写进注释）；显式浅色**不复制任何令牌块** |
| `src/components/AppHeader.vue` | 左侧三态按钮，44px，循环 跟随系统 → 浅色 → 深色；`aria-label` 说明"当前是什么、点了变成什么" |
| `src/main.ts` | 挂载前 `applyTheme(readTheme())`，避免首帧白闪 |

两处偏离原裁决，理由写在代码注释里：

1. 裁决写「`aria-pressed`」，实际**不用**：`aria-pressed` 表达开 / 关，套在三态循环上会让读屏读出"未按下"，而真实状态是"深色"。可读状态交给按钮文字，动作交给 `aria-label`。
2. 裁决里 `resolveTheme(choice, systemDark)` 没实现：JS 不需要知道"现在到底是深是浅"，CSS 的 media 查询已经回答；再算一遍就要监听系统切换、处理监听器泄漏，收益为零。换成 `themeAttr()`——它才是真正驱动 CSS 的那个值。

### N2 阅读目标

| 文件 | 改动 |
|---|---|
| `src/domain/goal.ts`（新） | `goalProgress(goal, sessions, finishedDays, today)`；闰年、大小月、年内第几天全部自算，不建 `Date`；`today` 入参，domain 不读时钟 |
| `src/lib/goal-prefs.ts`（新） | localStorage `bookrx.goal`；语义不明的 scope / metric 一律当"没设过"，避免"界面写每周、算法按年算" |
| `src/components/stats/GoalCard.vue`（新）+ `src/styles/goal.css`（新） | 进度条 + 还差多少 + 还剩几天 + 节奏判断；没设过目标时直接展开表单，不画 0% 空条 |
| `src/views/StatsView.vue` | 目标卡挂在 **v-if 链之前**：没读过书的人也能设目标，那也是他唯一能设的地方 |

「在轨」判据是 `(done + 1) * 总天数 >= 目标 * 已过天数`——**允许差一格**。严格按比例算，1 月 1 日、目标 12 本、进度 0 本会被判成"落后"，年初第一句话就是判决书。

## 2. 随行修正（都在本批范围内，不另起批次）

- **空分组不再各占一段**：提示语与组名同行，四个分组全空时页面高度从约 4×60px 降到 4×28px。
- **「试读示例」的出现条件**改为"书架上一本本机书都没有"：原来只要有书不在读 / 读完就会露出来，书架上摆着放下的书还劝人试读别的，读起来像推销。
